# Race Insights Dashboard

Create a assistant which can track the performance of a vehicle may be a F1 or any truck or any normal vehicle and then analyze and then give a dash board for it, start using a F1 car as initial test and further can be deployed in any other vehicle and this vehicle should be fully 3D and all the parts should be adjustable and has names for all the parts and also same goes to the sensors, the dash board consists of the track , performance and the results,
